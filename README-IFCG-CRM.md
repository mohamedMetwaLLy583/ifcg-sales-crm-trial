# مساحة فريق IFCG

تفتح مساحة الفريق من `http://127.0.0.1:8197/workspace` بعد تسجيل الدخول. صفحة الدخول العربية: `/login?lang=ar`. صلاحية كل موظف مرتبطة بدوره، والفرص والعملاء يتبعون نطاق الموظف أو فريق المبيعات. يوقف تغيير الحساب الجلسات القديمة.

## الأدوار

- مدير النظام الرئيسي: جميع المساحات، الأدوار، الاستثناءات وسجل التغييرات.
- مدير المبيعات: عملاء وفرص فريقه، توزيع الفرص غير المسندة، ومراجعة عروض الموظفين الآخرين.
- موظف المبيعات: عملاؤه وفرصه، المتابعات، الأنشطة وعروض الأسعار.
- التسويق: بيانات الشركات والحملات ومصادر الاستفسارات ومحتوى الموقع.
- التشغيل: أوامر البيع والعينات والشكاوى والتسليم.
- المالية: مراجعة التحصيل والبيع الآجل.
- الإدارة: قراءة التقارير والأوامر والبيانات الإجمالية.
- مسؤول الحسابات والنظام: حسابات الفريق وسجل التغييرات، دون صلاحيات مدير النظام الرئيسي.

ينشئ المدير حسابات الموظفين من «الفريق والصلاحيات»، ويضيف فرقًا ثم يربط كل مستخدم بفريقه. يلزم تعيين دور، فريق عند الحاجة، كلمة مرور لا تقل عن 12 حرفًا، وبريد عمل فريد. لا يمكن للمدير إيقاف آخر مدير رئيسي نشط أو تغيير دوره بنفسه.

## سير العمل

1. يسجل الموقع استفسارات العملاء في قائمة الفرص الجديدة؛ الحملات النشطة تقبل رموز UTM من صفحة الحملات.
2. يراجع مدير المبيعات الاستفسارات غير المسندة، ينشئ ملف الشركة وجهات الاتصال، ويسندها إلى فريقه.
3. يتابع الموظف العميل بمهام ومكالمات واجتماعات ورسائل مسجلة. يسجل النظام النشاط فقط؛ لا يرسل بريدًا أو رسائل.
4. ينشئ الموظف مسودة عرض بالسعر والعملة والخصم والشحن والتعبئة والتسليم والدفع. يحتاج اعتماد مدير آخر قبل تسجيل موافقة العميل. تحفظ الموافقة بمرجع عميل، ولا يكفي تغيير المرحلة يدويًا لإعلان الفوز.
5. يحول العرض المقبول مرة واحدة إلى أمر تشغيل. يسجل التشغيل مرجع الطلب الخارجي وتأكيد الإتاحة، وتراجع المالية التحصيل أو اعتماد الآجل، ثم يسجل التشغيل الشحن وإثبات التسليم.
6. تحفظ ملفات البيع والتشغيل والمالية في التخزين الخاص وتظهر للأدوار المخولة فقط. يسجل النظام تغييرات السجلات والقرارات.

## بيانات العملاء

يمكن إدخال الشركات من اللوحة أو استيراد ملف CSV بترميز UTF-8 وبحد 500 سجل. يجب أن تكون العناوين بالترتيب `name,email,country,phone,segment`. القيم المتاحة لحقل `segment`: `distributor`, `importer`, `restaurant`, `retail`, `private_label`. يتجاهل الاستيراد أي سجل يطابق اسم الشركة والبريد والبلد الموجودين.

## برنامج المخازن والمحاسبة الحالي

لم يتحدد اسم البرنامج أو وسيلة التكامل بعد. لذلك يحتفظ النظام بمرجع العميل ومرجع أمر البيع وتأكيد إتاحة المنتج ومرجع التحصيل الذي يدخله الموظف. لا يقرأ أرصدة المخازن أو الحسابات ولا يعدلها. لا يمثل تأكيد الإتاحة في مساحة IFCG حجزًا فعليًا للمخزون. بعد معرفة اسم البرنامج ووسيلة التصدير أو API، يلزم تحديد الحقول ومزامنتها قبل تشغيل تكامل آلي.

## حدود النسخة الحالية

الأسعار والعملاء التجريبيون الموجودون في قاعدة البيانات أمثلة وليست أسعارًا أو تعاقدات تجارية. مساحة الفريق محفوظة في نسخة المشروع المحلية وقاعدة SQLite الخاصة بها. لا توجد بعد خدمة مستضافة أو رسائل تلقائية أو تكامل ERP أو تحديث مخزون مباشر. انسخ قاعدة البيانات احتياطيًا قبل أي صيانة يدوية.

# IFCG website colour reference

Inspected 2026-11-10. This records colours observed on the live website, not a supplied corporate brand manual.

## Sources
- https://ifcgegypt.com/
- https://ifcgegypt.com/wp-content/uploads/2026/09/xts-theme_settings_default-1789290856.css?ver=7.1.3
- Homepage inline custom styles.

## Observed values
- Primary: #F89820, declared as --wd-primary-color and used by the footer.
- Alternative: #FBBC34, declared as --wd-alternative-color.
- Accent button green: #25A755, declared as --btn-accented-bgcolor.
- Dark green: #1F4626, used in homepage inline form-button styling.
- Related heading green: #1D4625, used in banner titles.
- Heading neutrals: #242424 / #333333.
- Body fonts: Lato; headings: Signika. Fonts were not changed in this colour-only correction.

## Local application
- Orange is used for brand emphasis and highlight surfaces, with dark text on orange buttons.
- Dark green is used for hero panels and primary actions, with white text.
- Bright green is available as a brand token; it is not used behind small white action text.
- Supporting light green backgrounds and grey borders are UI tints chosen locally, not claimed as official brand swatches.
- Removed the previously inferred burgundy/champagne palette and red logo backing.
